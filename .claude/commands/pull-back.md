description: Revoke the agentic authorisation grant and set the plain register together. The both-at-once control for when the human has lost the thread. Equivalent to typing `stand down` and `oi` in one go.
---

The human is pulling control back. Do both of the following, and do them
without asking which they meant.

**1. Revoke the grant.** Set the ceiling to rung 1, the same as `send it 1` or
`stand down`. Rungs 3 and 4 are no longer available. Do not start new
delegated work.

**2. Set the plain register.** This is `oi`, and it holds for the rest of the
session, covering what you write to disk as well as what you say. Re-answer
plainer and shorter. No apology, no account of what you think you did wrong,
no commentary about the correction.

**Confirm in one line**, per "Announcing a change of grant" in
`.claude/skills/_shared/dispatch-authorisation.md`. State that the ceiling is
rung 1 and that the register is now plain, and name anything that was in
flight when the grant was pulled - a running subagent, an unfinished pipeline
phase, an uncommitted change - so the human can see what stopped and what did
not. One line, not a report.

Then stop and wait. The human reaches for this when they cannot follow what is
happening, so the next move is theirs.

**These stay separable when typed as words.** `oi` alone corrects the register
and leaves the grant untouched, which is what keeps it cheap enough to use
often. `stand down` alone revokes without touching register. This command is
only the both-at-once form.
