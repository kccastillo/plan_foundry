## Field notes

- `schema_version` is always `1` in v1 of the INDEX format. A future breaking change increments this.
- `generated_at` is ISO 8601 UTC (`YYYY-MM-DDTHH:MM:SSZ`).
- `plans[]` contains one record per PLAN file. Records with missing frontmatter are included with defaults.
- `alerts` always contains all eight keys, even if the lists are empty.
- `recent_transitions` may be empty if the repo has no `plan-pipeline:` commits or git is unavailable.
- Mermaid graph rendering and incremental updates are NOT in v1; tracked for future dev.
